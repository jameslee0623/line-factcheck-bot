# LINE 家族查核機器人

**這是什麼：** 一個 LINE 機器人，幫你查核家族群組裡轉發的文章。有人貼新聞連結，機器人就用 Google 免費的 Gemini AI 幫你查證，用溫和的語氣回覆，並附上資料來源連結。程式跑在 Google Apps Script 上，不用自己架伺服器，費用是 $0。

**不用會寫程式。** 只要會複製、貼上、點滑鼠就好，大約 30 分鐘。

## 開始之前

你需要：

1. 一個 Google 帳號（Gmail）
2. 一個 LINE 帳號
3. 大約 30 分鐘

下面這些詞，你會在步驟裡看到，先用白話解釋一下：

- **API 金鑰** — 像一把密碼，讓這支程式可以使用 Gemini（Google 的 AI）
- **Channel access token** — 像一把密碼，讓這支程式可以用你的 LINE 機器人帳號發訊息
- **Webhook URL** — 一個網址，LINE 用它把訊息傳給這支程式
- **部署** — 把程式發布到網路上，這樣 LINE 才找得到它
- **指令碼屬性** — Apps Script 裡面一個安全放密碼的地方

---

## 第一部分：取得免費的 Gemini 金鑰（約 5 分鐘）

1. 打開瀏覽器，到 [aistudio.google.com](https://aistudio.google.com/)
2. 用你的 Google 帳號登入
3. 點左邊選單的 **Get API key（取得 API 金鑰）**
4. 點 **Create API key（建立 API 金鑰）**
5. 如果它問你要選哪個專案或要不要建立專案，直接按預設值繼續就好
6. 畫面會出現一串很長的代碼。**把它複製下來，存到安全的地方**（例如手機備忘錄）。這就是你的 Gemini 金鑰，像密碼一樣，不要貼到任何聊天室
7. 完成。不用付錢，也不用綁信用卡

## 第二部分：建立 LINE 機器人帳號（約 10 分鐘）

1. 到 [manager.line.biz](https://manager.line.biz/)，用你的 LINE 帳號登入
2. 點 **Create（建立）**，新增一個官方帳號
3. 幫它取個名字，例如 `查核小幫手`，國家選台灣，完成設定
4. 帳號建立好之後，在左邊選單找到 **Settings（設定）**，再找到 **Messaging API**，把它開啟
5. 再到 [developers.line.biz](https://developers.line.biz/)，用同一個 LINE 帳號登入
6. 點你的 channel（就是剛剛建立的帳號）
7. 點頁面上方的 **Messaging API** 分頁
8. 找到 **Channel access token**，點 **Issue（核發）**。畫面會出現一串很長的代碼——**複製下來，存到安全的地方**。這就是你的 LINE token
9. 在同一頁找到 **Allow bot to join group chats（允許機器人加入群組聊天）**，把它打開（**ON**）。它預設是關的，如果跳過這一步，機器人永遠進不了群組
10. 這個分頁先不要關，第四部分還會用到

## 第三部分：把程式碼放進 Google Apps Script（約 10 分鐘）

1. 到 [script.google.com](https://script.google.com/)，用你的 Google 帳號登入
2. 點 **New project（新增專案）**
3. 畫面上有一些範例程式碼（開頭是 `function myFunction`）。全部選起來，刪掉
4. 打開這個專案裡的 **`Code.gs`** 檔案，全部選起來，複製
5. 貼到 Apps Script 的頁面裡
6. 存檔：點磁碟片圖示，或按 Ctrl+S（Windows）／Cmd+S（Mac）
7. 點上方的 **Untitled project**，把專案改名為 `LINE Fact Check Bot`
8. 點左邊的**齒輪圖示**（Project Settings，專案設定）
9. 點 **Script properties（指令碼屬性）**，再點 **Add script property（新增指令碼屬性）**。下面 5 個，一個一個加。每次輸入名稱、輸入值，再按 **Save script property**：

   | 名稱（照這樣打，一個字都不能錯） | 值 |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | 第二部分第 8 步複製的 LINE 代碼 |
   | `GEMINI_API_KEY` | 第一部分第 6 步複製的 Gemini 金鑰 |
   | `GEMINI_MODEL` | `gemini-3.8-flash`（主要模型，最強的免費型號） |
   | `GEMINI_MODEL_FALLBACK` | `gemini-3.5-flash-lite`（備用模型，主要模型額度用完時自動改用它） |
   | `WEBHOOK_TOKEN` | 自己編一串亂碼英數字，例如 `aB3x9qZ7kL2`。記下來，第四部分會用到 |

   簡單講：平常都用 3.8 Flash（一天 20 次），用完了自動換成 Flash-Lite（一天 500 次），所以一天最多可以回答 520 次。

10. 完成。程式碼和密碼都存好了

## 第四部分：發布程式碼，接上 LINE（約 5 分鐘）

1. 在 Apps Script 裡，點右上角的 **Deploy（部署）**，再點 **New deployment（新增部署作業）**
2. 點「Select type」旁邊的齒輪圖示，選擇 **Web app（網頁應用程式）**
3. **Execute as（執行身分）：** 選 **Me（我）**
4. **Who has access（存取權）：** 選 **Anyone（所有人）**
5. 點 **Deploy（部署）**。Google 會問你要不要授權，選你的帳號，點 **Allow（允許）**
6. 畫面會出現一個網址，結尾是 `/exec`。**把它複製下來**
7. 在這個網址後面加上你的 token，長這樣：

   ```
   https://script.google.com/macros/s/ABC123/exec?token=aB3x9qZ7kL2
   ```

   把 `ABC123` 換成你自己的網址，`aB3x9qZ7kL2` 換成第三部分第 9 步你編的 `WEBHOOK_TOKEN`
8. 回到第二部分的 LINE Developers 頁面，把這個完整網址貼到 **Webhook URL** 的欄位裡，點旁邊的 **Update（更新）** 存起來
9. 存好之後，欄位下面會出現 **Verify（驗證）**，點它，應該會顯示成功
10. 把 **Use webhook（使用 webhook）** 打開（**ON**）
11. 到 Official Account Manager（[manager.line.biz](https://manager.line.biz/)）→ 你的帳號 → **設定 → 回應功能**，檢查這三個（這一步很重要，沒設好的話機器人收不到訊息）：
    - **回應模式**：選 **Bot（聊天機器人）**
    - **Webhook**：開（這是另一個開關，跟第 10 步的 Use webhook 都要開）
    - **自動回應訊息**：**關**。LINE 內建的自動回覆會搶走訊息，機器人就收不到了

## 第五部分：先測試（進群組之前先做）

1. 在 LINE 裡把你的新機器人帳號加為好友。用 LINE 搜尋它的名字，或掃它的 QR code（QR code 在 Official Account Manager 裡可以找到）
2. 傳訊息給它，試試下面其中一種：
   - 貼一個新聞連結
   - 打：`查 台積電要被美國罰款是真的嗎`
3. 等幾秒鐘。它應該會回覆查證結果和資料來源連結
4. 有回覆就代表成功了。如果沒有回覆，看下面的「出問題怎麼辦」

## 第六部分：邀請它進家族群組

1. 打開家族群組聊天室
2. 點上方群組名稱 → **Invite（邀請）** → 選你的機器人帳號 → **Invite（邀請）**
3. 機器人加入後會在群組裡打招呼，你就知道它進來了
4. 在群組裡貼一個新聞連結，機器人應該會在群組裡回覆
4. 完成。群組成員也可以打 `查` + 問題，或 @ 機器人來問

## 使用方式（給群組成員）

- **貼新聞連結** — 機器人會自己查證
- **打 `查` + 問題** — 例如：`查 普拿疼可以每天吃嗎`
- **打 `!fact` + 問題** — 一樣的意思，用英文
- **@ 機器人** — 打 @ 選機器人，再寫問題
- **回覆別人的訊息來查那則** — 長按別人的訊息 → 回覆 → @ 機器人（或打 `查`），機器人會查被回覆的那則，不是你回覆的文字。只認得最近 6 小時內的訊息，太久以前的請把文字複製給它
- **私聊機器人** — 傳任何訊息都會回，也可以傳照片或截圖給它查

## 設定面板（只有擁有者）

你（擁有者）不用開網站，就可以在 LINE 裡改設定。**只有你可以用**，群組裡其他人打不開。

**怎麼開：** 在 1:1 私聊裡，單獨傳送下面其中一個（整則訊息只有這幾個字，寫在句子裡沒用）：

- `設定`
- `setting`
- `settings`

**第一次打開時**，你就自動成為擁有者。之後只有你能改設定。

**面板裡可以改的：**

| 設定 | 說明 |
|---|---|
| 自動查核字數下限 | 預設 200 字。群組裡超過這個字數的訊息才自動查核，日常短訊不查。手動打 `查` 或 @ 機器人不受這個限制 |
| 連結內文抓取 | 開：機器人會先抓連結裡的文章內文再查核；關：只看連結本身 |
| 有字圖片 | 圖片裡有字的查核開關，1:1 和群組用同一個開關 |
| 影片 | 目前暫停，檔案和連結都不查 |
| 手動觸發 | `查`、`!fact` 等觸發詞，可以改 |
| 查核提示詞 | 機器人的語氣和規則，點「更改提示詞」後直接傳送新的文字 |
| 群組與成員 | 先選群組，再勾選這個群組裡哪些人會被自動查核 |
| 回覆長度上限 / 回答長度上限 | 回覆最多幾個字（預設 5000，LINE 單則訊息上限）、回答最多幾個 token（預設 2000），可以改 |

**群組與成員怎麼用：** 機器人沒有辦法自己列出它加入的群組，所以群組和成員是收到訊息時學到的——群組裡有人說話後，群組名字和說話的人才會出現在面板裡。選好群組後，勾選的人才會被自動查核；沒勾的人，機器人不會自動查他的訊息，但他打 `查` 或 @ 機器人還是可以用。

**不用面板也可以改：** 在 1:1 直接傳送 `字數 200`、`提示詞`，效果跟面板一樣。傳送 `取消` 可以離開進行中的設定。

**回覆長度上限和回答長度上限是什麼意思：**

- **回覆長度上限（預設 5000 字）：** LINE 一則訊息最多就只能 5000 字，設滿才不會把回答在來源清單中間切斷。超過還是會切斷，結尾會有「……」。
- **回答長度上限（預設 2000 tokens）：** 一個回答最多讓模型寫多少字，1 個 token 大約是 1 個中文字。回答本文大概 600 字，2000 是留很多空間的保險。設這個上限是為了保護，不是因為需要：LINE 的回覆期限只有 60 秒，模型寫太久會來不及回；寫太多也浪費免費額度。每天能問幾次是另外算的，跟這個無關。
- **來源連結不會被縮短：** 網址再長也不會截斷，截斷就打不開了。來源清單是機器人自己附的，不占模型的 2000 tokens；即時搜尋一次最多 5 條來源，所以加起來不會超過 5000 字。

面板最下面會顯示目前版本號（例如「版本 1.1.3」），改設定後重新打開面板就能確認新版本有沒有上線。

## 模型每月自動檢查

機器人用的 AI 模型（主要：Flash，備用：Flash-Lite）不用你手動換，也不在設定面板裡。機器人每月 1 號早上 9 點自己檢查一次：

- 現在用的模型還在 Google 的清單裡 → 什麼都不做，就算出了新模型也不換
- 現在用的模型已經退役（不在清單裡）→ 換成最新的 Flash（主要）或最新的 Flash-Lite（備用），換之前會先試一次，確認新模型真的能用

**不用做任何設定。** 打開設定面板（1:1 傳送「設定」）時，機器人會檢查排程，不存在就建立。面板最下面會顯示「每月檢查：已排程」或「未排程」。`setupMonthlyCheck` 留著當手動備用。

## 即時搜尋（Exa，免費）

Gemini 免費版不能用 Google 搜尋，所以機器人原本只能靠模型自己的知識回答。現在可以接 Exa 即時搜尋：先上網查，再把結果交給 Gemini 判斷，回答會附上來源連結。Exa 在測試裡比 Tavily 更常找到官方來源（政府、醫院、主流媒體），所以 1.1.17 從 Tavily 換成 Exa。

**要不要接都可以。** 沒接的話機器人照原本的方式回答（只是沒有即時搜尋）。

**申請金鑰（免費，不用信用卡）：**

1. 到 [exa.ai](https://exa.ai) 註冊帳號
2. 登入後到 Dashboard 複製 API key
3. 打開 Apps Script → 左邊齒輪 **專案設定** → **指令碼屬性** → 新增一筆：屬性名稱 `EXA_API_KEY`，值貼上你的 key → 儲存
4. 設定面板會顯示「即時搜尋 (Exa)：開」，就表示接好了

**額度：** 免費每月 $10 額度，一次搜尋約 $0.007，大約 1400 次。家族群組一天只問幾次，夠用。超過額度時搜尋會失敗，機器人自動照原本的方式回答，不會壞掉。

**什麼時候會搜尋：** 文字問題會搜尋（圖片不會；只有一個連結的訊息也不會，因為連結內文已經抓過了）。一次拿 8 個結果，讓模型可以交叉比對。

**可信度等級：** 每個搜尋結果會看網域分級：官方／權威來源（政府、醫院、大學）最高，主流媒體其次，一般網站只能當參考。模型會優先採用高級別的來源，說法不一致時會直接說出來。

**重點摘要和台灣：** 搜尋時會請 Exa 回傳問句相關的重點段落（highlights），而不是整頁文字開頭；沒有重點段落時才用整頁文字。也會告訴 Exa 使用者在台灣（userLocation: TW），讓結果更貼近台灣。

**不用 .cn 來源：** 問題沒提到中國時，搜尋結果會先去掉 .cn 網站，還有新華社、央視、中新社、環球網（它們是 .com，.cn 規則抓不到）。問題提到中國（中國、大陸、中共、兩岸、香港、澳門、北京、上海）時才用 .cn 來源，因為那時它們才是第一手資料。

**不可靠來源名單（每月更新）：** 每月 1 號早上 9 點的檢查除了換模型，也會更新名單：從 CRED-1（分數 ≤ 0.50 的網域）、uBlacklist 假新聞清單和 Content Farm Terminator 的內容農場清單（每月更新，41,147 行）下載，合併去重後存在指令碼屬性。內容農場清單太大，先去掉單一垃圾部落格（pixnet、fc2、wordpress）、純數字網域和 IP，再把同結尾的網域壓縮存在一起（每格 9 KB 上限，切成 DENY_0、DENY_1……）。搜尋結果裡有這些網域就直接去掉，任何問題都一樣。設定面板最下面會顯示名單最後更新日期。如果下載失敗，舊名單繼續用，不會影響回答。第一次部署後，在編輯器裡跑一次 `updateCredibilityLists`，名單馬上載入；不跑也沒關係，下個月 1 號會自己更新。

**開關：** 設定面板裡「即時搜尋 (Exa)」有切換按鈕，關掉就暫時不用搜尋，金鑰會留著，不用重設。

**來源清單是機器人自己附的：** 回答裡的 [1]、[2] 編號和清單對得上，不會漏掉或對錯（之前模型自己寫的清單會漏 [1]，1.1.11 修掉了）。

## 費用

$0。原因：

- Gemini（Google 的 AI）免費額度夠用——一天大約可以問 100 到 1000 次，家族群組問的次數遠低於這個

- Google Apps Script 免費

## 出問題怎麼辦

| 發生什麼事 | 怎麼辦 |
|---|---|
| Webhook **Verify（驗證）** 顯示 **302 Found** | 這是正常的，不是你的錯：Apps Script 的 `/exec` 網址一定會回 302（轉到 `script.googleusercontent.com`），LINE 不跟轉址，所以 Verify 永遠不會顯示成功。程式本身有正常執行 — 直接用第五部分的 1:1 測試傳訊息給它，有回覆就代表正常，不用管 Verify 的紅字 |
| Webhook **Verify（驗證）** 失敗（其他錯誤） | 網址錯了，或 `?token=` 後面那串跟第三部分存的 `WEBHOOK_TOKEN` 不一樣。兩個都檢查一遍再試一次。另外確認部署時的存取權是 **Anyone（所有人）**（第四部分第 4 步） |
| 機器人完全不回 | 在 Apps Script 裡，點左邊的**時鐘圖示**（Executions，執行紀錄）。如果裡面什麼都沒有，表示訊息根本沒傳到程式——回去檢查 webhook 網址。如果裡面有錯誤訊息，照下面幾列對照 |
| 機器人回：今天問太多了 | 主要模型（一天 20 次）和備用模型（一天 500 次）的免費額度都用完了，明天再試 |
| 機器人回：查核服務出錯了（503） | Google 那邊暫時太忙，不是額度用完。機器人會等 2 秒再試一次；如果還是這樣，等一下再問一次，通常就好了 |
| 機器人回：模型名稱可能已退役 | Google 把那個 AI 型號名稱停用了。機器人會在每月 1 號的檢查時自動換成最新的模型，不用你動手。如果等不及，到指令碼屬性改 `GEMINI_MODEL`（第三部分第 9 步），存檔 |
| 私聊會回，群組不會回 | **Allow bot to join group chats** 還是關的（第二部分第 9 步），或機器人還沒被邀請進群組（第六部分） |
| 回得很慢或沒回 | AI 偶爾會超過 50 秒，而 LINE 只等 1 分鐘。再問一次，通常第二次就好了 |

## 安全提醒，請看一下

- **3 組密碼絕對不要分享**（Gemini 金鑰、LINE token、webhook token）。不要貼到任何群組，也不要寫進程式碼裡——它們只能放在指令碼屬性裡
- **不要分享 webhook 網址**，裡面有你的秘密 token
- 免費版 Gemini 可能會拿你的訊息去改善 Google 的產品，所以不要傳私密內容
